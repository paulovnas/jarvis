## Novidades

- Muse Code como provedor por assinatura, com modelos, autenticação pelo CLI, consulta de limites e busca web disponível aos demais modelos do Jarvis.
- Editor do chat com formatação Markdown e mensagens enviadas com títulos, listas e destaques formatados.
- Nomes de apresentação personalizáveis para provedores e indicadores de reserva e déficit no limite mensal do OpenCode Go.
- Refinamento de prompts continua ao navegar entre chats e pode ser cancelado preservando o texto original.
- Bandeja do sistema no macOS, com ícone mais discreto e correção do fechamento inesperado ao abrir o menu.

## Correções

- Ativar um MCP mantém o catálogo e a ativação dos demais disponíveis durante a execução e em conversas já afetadas. Preferências comuns deixam de virar restrições exclusivas; seleções explicitamente exclusivas continuam sendo respeitadas.
- MCPs sob demanda não são conectados antecipadamente por preferências herdadas. A falha ao ativar uma integração não impede consultar o catálogo e ativar outra.
- Ferramentas de navegador passam a ter prioridade explícita para páginas web e Impeccable Live. O controle nativo fica orientado a aplicativos, interface do navegador, diálogos do sistema ou uma limitação comprovada das ferramentas de navegador.
- Login OAuth para MCPs manuais e de plugins, callback de autenticação atualizado e separação dos MCPs de plugins nas configurações.
- Retomada com Codex após trocar de provedor, compatibilidade dos identificadores de ferramentas e recuperação de operações do navegador Firefox.
- Aprendizados automáticos passam a exigir orientações técnicas explícitas para lembrar ou reforçar instruções repetidas, sem registrar requisitos comuns e regras de negócio.
- Muse Code segue o padrão de velocidade das demais integrações quando há dados do provedor e permite escrita e execução de comandos conforme as permissões da sessão.

## Validação e limites

- Publicação com instaladores e atualizadores para macOS Apple Silicon, Windows x64 e Linux x64, sujeitos à compilação e verificação de cada plataforma no CI.
- As validações locais foram realizadas no macOS. Compilação no CI não substitui testes interativos no Windows e Linux.
- A assinatura Muse Code usada no desenvolvimento foi cancelada; funcionalidades dependentes da conta não receberam nova validação online nesta publicação.
