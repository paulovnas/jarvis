# Jarvis 0.8.1 Beta

## Novidades e ajustes

- O aplicativo e os novos instaladores agora usam **Jarvis**, com J maiúsculo.
- **Sobre o Jarvis**, no menu do macOS, abre a mesma modal de versão e atualizações da statusbar.
- Ao verificar atualizações manualmente, uma confirmação verde informa quando a versão mais recente já está instalada.
- O botão **+** de cada projeto cria uma conversa diretamente nele. O menu geral oferece apenas workspace e projeto.
- Corrigido um caso em que a verificação de atualizações do Core fazia o progresso de download retroceder.

## Atualização

Na versão 0.8.0 Beta instalada, clique na versão junto às configurações e em **Verificar atualizações**. Depois, escolha **Atualizar e reiniciar**. O pacote é assinado e a reabertura automática preserva os dados locais do Jarvis.

Distribuição para macOS com Apple Silicon. Esta beta ainda não possui notarização da Apple.
